📚 Метод Стюарта

Три независимые переменные:

  1. pCO₂ — респираторный компонент
  2. SID — сильная ионная разница
  3. A_tot — слабые кислоты (альбумин, фосфаты)

SID_a = (Na⁺ + K⁺ + Mg²⁺) − (Cl⁻ + Лактат⁻)

SID_e = HCO₃⁻ + заряд альбумина + заряд фосфата

SIG = SID_a − SID_e. Норма 0–2. >2 → накопление неизмеряемых анионов.

📚 Winter's

Мет. ацидоз: pCO₂ = 1.5×HCO₃⁻ + 8 ± 2

Мет. алкалоз: pCO₂ = 0.7×HCO₃⁻ + 21 ± 2

Острый респ. ацидоз: HCO₃⁻ +1 на 10 мм рт.ст. pCO₂

Хронический респ. ацидоз: HCO₃⁻ +3.5 на 10 мм рт.ст. pCO₂

📚 SBE-разбивка

SBE_FW = 0.3×(Na−140)

SBE_Cl = 104 − Cl×140/Na

SBE_Alb = (0.148×pH−0.818)×(40−Alb)

SBE_UA = SBE − FW − Cl − Alb

ΔАП ≈ −SBE_UA

📚 Анионный gap

АП = Na⁺ − (Cl⁻ + HCO₃⁻). Норма 8–12

АП_корр = АП + 0.25×(40−Alb). Норма ≤14

ΔAG = АП_корр − 12

ΔΔ = ΔAG/ΔHCO₃⁻. <1 → NAGMA; >2 → мет. алкалоз; 1–2 → HAGMA
