📚 ФИЗИКО-ХИМИЧЕСКИЙ ПОДХОД СТЮАРТА

SID_a = (Na⁺ + K⁺ + Mg²⁺ + Ca²⁺) − (Cl⁻ + Лактат⁻)

SID_e = HCO₃⁻ + заряд альбумина + заряд фосфатов

SIG = SID_a − SID_e. Норма: 0–2 мЭкв/л.

📚 ПРАВИЛА WINTER'S

Мет. ацидоз: pCO₂ = 1.5 × HCO₃⁻ + 8 (±2)

Мет. алкалоз: pCO₂ = 0.7 × HCO₃⁻ + 21 (±2)

📚 ТАБЛИЦА 4.6 — ЗНАЧЕНИЯ ΔΔ

ΔΔ < 0.4 → Гиперхлоремический ацидоз (NAGMA)

ΔΔ 0.4–0.9 → Смешанный (NAGMA + HAGMA)

ΔΔ 0.9–2.0 → Ацидоз с увеличенным АП (HAGMA)

ΔΔ > 2.0 → HAGMA + метаболический алкалоз

📚 ГИПЕРХЛОРЕМИЯ — 2 УРОВНЯ

Абсолютная: Cl⁻ > 107 ммоль/л

Относительная: Cl⁻ в норме, но Na − Cl < 38 или Na/Cl < 1.37 → низкая SID

Относительная гиперхлоремия способствует мет. ацидозу (окисляющий эффект низкой SID).
